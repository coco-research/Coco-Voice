## Safer, smarter model downloads

This release is about downloading models. Every model in the catalog is now
pinned to a fixed version and checked against its known fingerprint before it
is used, so a changed or damaged file is caught. Models you already downloaded
stay in place through this change, so you don't need to download them again.

- Cancelling a model download stops only that download.
- A model that is already in the shared cache on your computer is reused instead of
  downloaded a second time.
- Models that aren't offered for licence reasons are now blocked from every
  download source.
- Whisper large-v3-turbo now shows its correct licence (MIT).

## Clearer shortcut errors

If a shortcut can't be registered, Coco Voice now says why and offers a
Try again button.
