## Model changes

Coco Voice now offers only models whose licences allow it. 18 models are no
longer offered and sense-voice-int8 is removed. If you used one of them, it
won't load after this update: pick another model in Settings > Models
(Parakeet V3 is a good default). The full list is in the README under
[Models no longer offered](https://github.com/coco-research/Coco-Voice/blob/main/README.md#models-no-longer-offered).

## A more dependable Coco Voice

This release is about reliability. Dictation now recovers by itself after an
internal error, a model that fails to load no longer leaves the app stuck, and
a streaming transcription that times out no longer blocks the next one.

Smaller fixes:

- Mute while recording no longer leaves your speakers muted.
- A failed shortcut change keeps your old shortcut working.
- Spoken corrections replace exactly the right text, emoji included.

## New signing key

Coco Voice 0.9.5 is signed with a new update key. Copies on 0.9.4 cannot
update to it automatically: download 0.9.5 once from the release page. On
macOS, grant Accessibility to Coco Voice again after installing; that is a
one-time step. Later updates arrive through "Check for updates" as usual.
