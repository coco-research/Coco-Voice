# Security Policy

## Supported versions

Only the latest release of Coco Voice receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub private vulnerability reporting](https://github.com/coco-research/Coco-Voice/security/advisories/new).

Include the version, your operating system, and steps to reproduce. We aim to
reply within 7 days and to ship a fix in the next release.
